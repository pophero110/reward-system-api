
### MVP

- [ ] **As a kid, I want to view a list of available quests so that I can see how to complete them and earn rewards.**
- [ ] **As a kid, I want to accept a quest so that I can complete the quest and earn rewards**
- [ ] **As a kid, I want to complete a quest so that the adult can review it and provide the reward.**

- [ ] **As an adult, I want to post new quests so that the kid has tasks to complete.**
- [ ] **As an adult, I want to review completed quests so that I can provide the reward promptly.**
- [ ] **As an adult, I want to update a quest so that I can update the quest’s details, such as reward, due date, description, title, or status.
- [ ] **As an adult, I want to delete a quest so that I can correct my mistakes**.

- [ ] **As a kid or an adult, I want to add comments to a quest so that we can share feedback.** 

- [ ] **As an adult, I want to invite my kids to the quest board so that my kids can view quests and accept quests**
- [ ] **As an adult, I want to create a quest board so that I have a place to post quests for my kids.**

### Advanced

- [ ] **As an adult, I want to add tags to quests so that I can categorize quests by tag.**
